# Day 28 - WiFi: Web Server on Pico W

## 📖 Introduction
Create an HTTP web server on Pico W. Access it from a browser to view sensor data and control GPIO.

---

## 🎯 Key Concepts
- TCP server listening on port 80
- Parse HTTP request (GET/POST)
- Serve HTML response
- REST API for IoT control

---

## 🏋️ Challenge
1. Serve HTML page displaying temperature
2. Button on web page to toggle LED on/off
3. Auto-refresh data every 5 seconds
